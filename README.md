## Cómo trabajo

Primero intento identificar a la persona que va a usar el sistema y el problema que necesita resolver. Después organizo los datos y pruebo el recorrido completo: lo que se registra, lo que cambia y lo que podría perderse.

Uso herramientas de IA para prototipar, desarrollar y revisar código. En los casos del portafolio cuento dónde participaron y qué comprobé después. Me interesa aprovecharlas sin saltarme la parte de entender, probar y corregir.
